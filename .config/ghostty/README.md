# Ghostty

Configuration for [Ghostty](https://ghostty.org/), a fast, native terminal emulator.

## Highlights

- Uses Zsh for shell integration.
- Uses Fira Code with ligatures enabled.
- Uses the Catppuccin Mocha theme and `xterm-256color`.
- Clears the default keybindings and defines a small custom set for reload,
  font-size changes, copy, and paste.

The configuration is stored in [`config`](config) and is installed to
`~/.config/ghostty/config` by GNU Stow.
